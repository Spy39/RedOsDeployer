# RedOS Deployer 🚀

**RedOS Deployer** — это консольная утилита на C# (.NET 8) для автоматизированной настройки, обновления и развертывания операционной системы РЕД ОС (версии 7/8). Разработана специально для ускорения массового ввода ПК в эксплуатацию в образовательных учреждениях.

Утилита выступает в роли оркестратора: она предоставляет удобный интерактивный интерфейс для системного администратора, проверяет состояние системы и управляет выполнением атомарных Bash-скриптов.

## 🛠 Ключевые возможности

* **Умные обновления:** Поддержка как полностью офлайн-обновлений (через локальные репозитории на USB-накопителе), так и онлайн-докачивания патчей.
* **Массовая установка ПО:** Автоматическое разрешение зависимостей и установка корпоративного пакета (Р7-Офис, Яндекс.Браузер, Мессенджер MAX).
* **Управление периферией:** Интерактивное меню установки драйверов для принтеров (Brother, Canon, HP, Samsung) с возможностью расширения через конфигурационный файл.
* **Системные твики:** Настройка загрузчика GRUB для Dual-Boot (Windows/Linux), очистка старых ядер, синхронизация времени.
* **Безопасность и логирование:** Защита от случайного прерывания (Ctrl+C), проверка прав `root` перед запуском, подробное логирование всех действий в `/logs`.

## 📁 Структура проекта (Окружение)

При запуске утилита автоматически создает необходимую структуру папок рядом с исполняемым файлом:

```text
/RedOsDeployer/
├── RedOsDeployer           # Исполняемый файл утилиты
├── config.json             # Файл настроек (списки ПО и принтеров)
├── scripts/                # Исполнительные Bash-скрипты
├── repo/                   # Локальный офлайн-репозиторий (base, updates)
├── apps/                   # .rpm пакеты для установки
└── logs/                   # История выполнения (deploy_log.txt)
```

## ⚙️ Настройка (config.json)

Программа использует гибкую конфигурацию без необходимости перекомпиляции кода. В файле `config.json` можно задать целевые пакеты для проверки и добавить новые принтеры.

Пример добавления нового принтера в `config.json`:

```json
"Printers": [
  {
    "Name": "Новый Принтер Pantum",
    "FolderName": "PANTUM",
    "InstallScript": "install.sh"
  }
]
```

## 🚀 Сборка и запуск

Проект собирается как **Self-Contained Single File**, что позволяет запускать его на "голой" РЕД ОС без предварительной установки .NET Runtime.

Команда для публикации (из корня проекта):

```bash
dotnet publish -c Release -r linux-x64 --self-contained true -p:PublishSingleFile=true
```

**Запуск на целевой машине:**
Утилита требует прав суперпользователя для выполнения системных команд `dnf` и `systemctl`.

```bash
sudo ./RedOsDeployer
```
